# 股票交易账本 V5.0

## 更新内容
- 年度月度盈亏视图：按 12 个月显示月度盈亏，左右切换年份，不再按日展示。
- 新增买卖记录后立即重新查找股票代码并获取当前报价；内置常见股票代码，并尝试名称精确匹配。
- 行情接口跨域、限流、名称无法识别时，显示明确提示，可在“行情/手动价格”填写代码或现价。并不保证交易所实时行情。
- 精细化金融软件配色、间距、渐变状态色、暗色模式。
- 保留 v4/v3 使用的 `stockledger.pwa.v1` 本地交易数据键与 `stockledger.ui.v4` 偏好设置键；未改原始数据结构。
- 保留历史盈亏按个人60%份额录入的规则。

## 部署
先在原应用右上角设置中导出 JSON 备份。解压本 ZIP，**上传文件夹内的所有文件到 GitHub 仓库根目录**，覆盖旧文件并提交，保持原 GitHub Pages 地址。请勿直接上传 zip 或上层文件夹。等待 Pages 发布后重新加载；iOS PWA 若有旧缓存，退出并重新打开。

## 行情限制
自动行情仅作参考，依赖未承诺稳定性的公开第三方接口，不保证实时、完整或持续可用。代码查询失败时，应人工补填六位股票代码。禁止依赖该页面报价作为下单依据。

## 兼容
新版保留 localStorage 键和 JSON 备份格式；建议更新之前保存 JSON。若从不同域名打开，浏览器不会自动共享本地数据。
