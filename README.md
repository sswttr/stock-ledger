# 股票交易账本 V4（iPhone PWA）

## 安装
把本文件夹中的 `index.html`、`style.css`、`app.js`、`sw.js`、`manifest.webmanifest` 和 PNG 图标上传至 GitHub 仓库**根目录**，在仓库 Settings → Pages 开启 main / (root)。通过 Safari 访问 HTTPS 地址，分享 → 添加到主屏幕。

## V4 改动
- 根据用户提供的浅色 / 深色红绿日历视觉参考重新设计。
- 三个底部页面：总览、记一笔、明细；右上角齿轮设置（外观/行情/备份）。
- 总览已实现盈亏显示本人60%、对方40%、整体100%。持仓表列出市值、浮动总盈亏、比例、双方份额、持仓天数。
- 当月成交表；月度/累计已实现盈亏图；红盈绿亏的月历。
- 买入/卖出记录不必填写代码或账户；默认佣金万分之一（允许改动），卖出税万分之五（自动计算）。佣金无最低收费额假设，券商实际费用可能不同。
- 保留历史五笔记录，金额为本人60%所得，原有本地储存键 `stockledger.pwa.v1` 不变，可直接兼容以前的JSON备份。
- 公开东方财富行情接口可能被浏览器 CORS 或网络策略阻止，且可能非实时；显示刷新结果，不伪造市场价。设置 → 管理行情可填写6位代码或手动价格。无报价则市值/浮盈亏显示“—”。

## 计算口径
- 卖出已实现盈亏：移动加权平均成本。
- 持仓天数：先进先出匹配，用数量加权；买入时在明细显示买入时间、卖出时显示卖出时间（不会伪造每一股的原始逐笔买入时间）。
- 历史盈亏日期是记录日期，不保证为卖出日。没数据的买卖时间显示“—”。
- 分成正负盈亏均按60/40计算。历史金额视为本人60%，反算整体时有分钱四舍五入差异。
- 盈亏概览和收益走势仅含**已实现**，持仓浮盈亏另列，不会混加。

## 隐私与限制
数据仅在设备的浏览器 localStorage。无账户、无云同步。清除浏览器数据可能丢失，务必定期导出JSON。公开仓库只放程序文件，不上传真实交易JSON。静态网页无法保证实时市场行情，也无法绕过行情商API权限和跨域限制。尚未在真实iPhone设备上测试。
